# Tic-Tac-Toe

A simple Tic-Tac-Toe game built using HTML, CSS and JavaScript.

## Features

* Two-player Tic-Tac-Toe
* Win detection
* new game button
* Restart game button

## Technologies

* HTML
* CSS
* JavaScript
